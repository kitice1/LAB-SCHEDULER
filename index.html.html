Google Sheets 연결이 필요해요

Firebase 없이 구글 스프레드시트를 DB로 사용해요. Google 계정만 있으면 돼요! (무료, 2FA 불필요)

1

Google 스프레드시트 만들기

sheets.new 열기 → 새 스프레드시트 생성 (이름은 아무거나)

2

Apps Script 열기

스프레드시트 상단 메뉴 → 확장 프로그램 → Apps Script 클릭

3

백엔드 코드 붙여넣기

기존 코드 전부 지우고 → 받은 apps_script_code.gs 파일 내용 붙여넣기 → Ctrl+S 저장

4

웹 앱으로 배포

오른쪽 위 배포 → 새 배포 클릭

유형: 웹 앱 다음 사용자로 실행: 나(Me) 액세스 권한: 모든 사용자(Anyone) → 배포 클릭 → URL 복사
5

이 HTML 파일에 URL 붙여넣기

텍스트 편집기로 이 파일 열기 → 아래 부분 찾아서 복사한 URL로 교체:

const API_URL = 'YOUR_APPS_SCRIPT_URL';
